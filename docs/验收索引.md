## 5. 全部可运行的自检（给 AI 检查用）

```bash
cd week1

# 网页静态检查：JS 语法 / 元素 id / 接口连通性

# 第2周：指令链路（无硬件）

# 第2周：真浏览器点「重新采集」并核对四阶段

# 第3周：按键链路（无硬件：上报→聚合→与定时/指令隔离）
python tools/btn_selftest.py

# 第3周：真实浏览器核对求助面板与三级反馈
python tools/browser_test_help.py

# 网页改版审计（分区、画布尺寸、徽标两态、hash 直达、无 JS 报错）
python tools/web_audit.py

# 断网实测：取基线 → 停服 → 确认静默 → 人按键 → 判读
python tools/offline_test.py snapshot --tag before --out debug_logs/_offline_before.json
python tools/offline_test.py compare debug_logs/_offline_before.json debug_logs/_offline_after.json
```

> 这些脚本的共同原则：**只观察、不伪造**。需要人按键的脚本会等人，没人按就如实报"没等到"。

## 6. 已知缺口（不藏）

1. **VPS / 公网远程访问未做** —— 只有局域网可达，固件 `SERVER_URL` 写死。
2. **三课共同核对无书面纪要** —— 完成状态依据学生自述，仓库只留我方材料。
3. **同伴走查由 AI 参与** —— 依据教师确认（学生转述），记录里已注明 AI 非零上下文、真人追问未做。
4. **`help_reply` 回执单槽位** —— 连点两条控制指令时，前一条会 `exec` 超时（真机已复现），验收演示时不要连点。
5. **按键响应受 HTTP 阻塞** —— `press_delay_ms` 在 0.4~1.2 s 波动，根治需把 HTTP 挪到独立任务。
