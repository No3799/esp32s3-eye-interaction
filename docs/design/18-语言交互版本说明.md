## 二、能做什么

| 能力 | 表现 |
|---|---|
| **一句话查数据** | 「查看上次数据」→ `query_latest` → 回答带数值、该条记录自己的时间、来源（设备 + 记录 id） |
| **一句话要采集** | 「重新采集一次」→ `request_recollect` → 下发指令，等回执与新记录，回答带 `CMD-…` 与状态 |
| **含糊不瞎执行** | 「看看数据吧」→ `intent=unclear`，列出可选项让人选，不做任何动作 |
| **越界拒绝** | 「问坐标」→ 明确回答"没有定位数据源"，不编经纬度；`device999` → `device_not_allowed` |
| **澄清可接** | 反问后**只回一个字**（"读"/"采"）也能接上，上下文只在 180 秒内有效 |
| **中途取消** | 「停止」或 Esc：原子任务作废、停播报、回空闲 |
| **迟到结果隔离** | 取消后晚到的回答**不播报、不写对话、不改状态** |
| **反悔可恢复** | 取消时把那句话**填回输入框并选中**，不自动重发；同时说明"设备指令不会被撤回" |
| **服务挂了说清楚** | 语言服务不可用 → 明确报错并给结构化样例，**不瞎猜意图去执行** |

## 三、不能做什么（边界写在这里，避免误解）

- **不会推理出数据里没有的东西**：模型只输出 `{intent, params}`，回答里每个数字、时间、状态都由服务端从工具返回值拼。模型改不动这些。
- **不能撤回已下发的设备指令**：取消只让本页不再采用结果，设备照常采完。
- **不是全双工**：按一下说、再按一下结束。唤醒词、回声消除、边说边听**都没做**。
- **不训练模型**：用的是现成预训练权重（`qwen3.8-q2`），零训练零微调。
- **不认多个设备同时说话**：设备范围按活跃度判定，未指明时只看 5 分钟内活跃的设备。
- **板子不会出声**：板上没有扬声器，播报只发生在浏览器。

## 四、交互状态

```
空闲 ──发送/录音──► 处理中 ──有结果──► 播报中 ──播完──► 空闲
                      │                    │
                      └──按停止/Esc────────┴──► 已取消 ──（填回原文）──► 空闲
                            （代数 +1，在途请求 abort，迟到结果丢弃）
```

四个可观察状态：**录音中 / 识别中 / 执行中 / 播报中**。
坏在哪一环，界面上就停在哪一环 —— 不会笼统显示"语音不能用"。

## 五、接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/ask` | 文字或识别后的文本 → 意图 + 工具 + 基于真实结果的回答 |

## 七、已知限制（如实列出）

1. **本机没有扬声器**：播报引擎实跑 4.27 秒有日志，但没有"人耳听到"的证据。
2. **语言服务要单独起**：`week1\启动语言服务.bat`。直接开 Ollama 托盘程序会导致
   `/api/tags` 为空、全部意图解析失败（模型目录是 junction，托盘程序读不到）。
3. **识别是离线的**：Vosk 中文模型，不联网；复杂句、方言、远场效果没测过。
4. **上下文只有 1 条**：只能接住"上一个问题"，不支持长对话。
5. **半双工**：说话时听不到系统播报，反之亦然。
