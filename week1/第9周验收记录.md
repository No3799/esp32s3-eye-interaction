## 一、怎么决定"要不要问"

主动询问最容易犯的错不是"不问"，是**太积极**。拍坏一次问一次，用户两下就把它关掉，
关掉之后真正需要提醒的时候也不会再响。所以判断逻辑放在服务端（`proactive.py`），
前端不自作主张 —— 前端自己判断"该不该打扰人"，迟早会出现两处口径不一致。

三道闸，顺序执行：

```
① 全局静音中？        → 不问（还有 N 秒恢复，理由里写着）
② 画面能用（usable）？ → 不问（问了就是打扰）
③ 这张被忽略过？      → 不问（1800 秒窗口内）
④ 否则：blocked / unclear / 不确定 → 问
```

**冷却为什么用时间而不是次数**：次数用完就永远静音，"别再问"变成了"拆掉功能"。
10 分钟是个折中 —— 短了像没记住你的选择，长了等于把功能关了。

## 二、实测（`tools/test_week9_proactive.py`，原始输出）

```
[1] 画面能用时，不该问
    SNAP-20261102-150017-264f 标签=usable -> ask=False  理由：画面能用，不打扰
    ✓ 没有打扰

[2] 画面看不清时，问一次
    SNAP-20261102-145947-1cdf 标签=blocked -> ask=True  理由：画面被挡住了，问一下要不要重拍

[3] 说「这次算了」之后，同一张不再问
    再次推理同一张 -> ask=False  理由：这张你已经忽略过了，不再问
    ✓ 记住了你的选择

[4] 说「别再问」之后，冷却期内全部静音
    状态: muted=True  剩余 599 秒（冷却 600 秒）
    冷却期内推理另一张 SNAP-20261102-145947-7f86 -> ask=False
      理由：你刚说过别再问，还有 599 秒才恢复
    ✓ 静音生效
    再次读取状态（落盘）: muted=True 剩余599秒  最近事件 2 条

[5] 反例：非法动作要拒绝
    action=whatever -> HTTP 400 ✓ 被拒
```

第 [4] 步特别看了**换一张图**会不会绕过静音 —— 会绕过就等于没静音。
结果是没问，说明冷却作用在全局而不是按图记。

## 三、问题归因与修复（按三类）

| 类别 | 问题 | 归因 | 修复 |
|---|---|---|---|
| **模型** | 四张样例自报分数全是 0.90，判断却对错各半 | 未校准模型的自评分没有区分度 | 不改模型（改不了），改**口径**：全链路只出现 `self_reported`，页面写"未校准"，不出现任何正确率 |
| **模型** | 把"失焦"判成"被遮挡" | 模型把"看不出内容"和"被挡住"混成一档 | 保留三档标签，靠**人工纠正**回写；纠正记录与原判并列，不覆盖 |
| **端侧** | 模型不可用时接口仍写了一条 `rejected` 记录 | 把"系统故障"和"模型判不出来"混成一个统计 | 模型不可用直接 503，不落库 |
| **交互** | 忽略过的图仍会被再问（第一次跑测试时 [2] 失败） | 上一轮验收脚本对每张图都自动发过 ignore，属于**测试用例**问题，不是逻辑问题 | 清掉询问记录重跑；逻辑本身正确（忽略过就该不问） |

## 四、界面上那一行"跑在哪"

任务卡要求"演示中说明模型、设备及服务实际运行位置"。嘴上说一遍很容易糊过去，
所以直接写在页面上（`#visWhere`），每次打开都能看到：

```
服务：本机 127.0.0.1:8000（不是云端）　·　
模型：本机 Ollama · qwen2.5vl:3b（3.8B / Q4_K_M / fb90415cde1e）　·　
设备：ESP32-S3-EYE 10.1.41.160（WiFi 上报，非 USB 桥接）
```

这三个位置写清楚，是为了避免一个常见的误会：**看起来像"云服务在识别"，
其实是本机一个 3.8B 的小模型在看图**，而且板子是自己连 WiFi 传的，不是插着线。

## 五、坑

1. **测试用例会把状态带进下一轮**。第一次跑 [2] 就失败，理由是"这张你已经忽略过了" ——
   上一轮脚本自动发过 ignore。**逻辑没错，是数据被上一轮污染了。**
   以后跑这类有状态的验收，先想清楚"上一次跑留下了什么"。
2. **静音要能拦住"换一张图"**。一开始只验"同一张不再问"，
   后来补了"冷却期内换一张也不问" —— 只按图记的静音等于没静音。

## 六、这一周的一句话结论

**画面不能用时它会主动问一句，你拒绝之后它真的闭嘴。**

具体说：usable 不问、blocked/unclear 问一次、忽略后同张不问、静音后全局不问且落盘；
误判能纠正且原判留档。缺的是真人首轮任务测试和三课统一样例（已如实标注）。
