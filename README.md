# 第 4 周 · 用一句话查数据、要一次采集

> 这是**第 4 周结束时**的仓库快照。整门课的完整说明看
> [`main` 分支](https://github.com/No3799/esp32s3-eye-interaction/tree/main)。

网页上按钮一多，人就得记住点哪个。这一周让系统听懂一句话：

- 「上次的数据是多少」→ 读一条**已有记录**
- 「现在采一次」→ 下发一条**采集指令**

最要紧的一条约束：**模型只出参数，不出结论**。回答里每一个数字、时间、状态，
都由服务端从工具返回值拼出来 —— 模型说错了也没有权力改。

## 一、这一周做了什么

| 做了什么 | 落在哪 |
|---|---|
| 三个角色分清：开发助手（写代码的 AI，权限极大）≠ 产品运行时模型（只输出 `{intent,params}`）≠ 受限工具（读一条 / 下发一条） | [`docs/design/13`](docs/design/13-自然语言助手与受限工具.md) |
| 接入本地 Ollama 的预训练模型 `qwen3.8-q2`，**零训练零微调**；`chat_json()` 强制 `format=json` | `server/nl_agent.py` |
| 两个受限工具：`read_latest()` 读一条、`request_recollect()` 下发一条 —— **复用已有接口，未新增任何通信协议，固件未改** | 同上 |
| 参数限幅 `samples∈[1,100]`、`interval_ms∈[20,1000]`；越界**在回答里说明**，不静默改 | 同上 |
| 设备范围按活跃度：未指明只认 5 分钟内活跃的设备；点名时可查历史设备；请求采集额外要求活跃 | 同上 |
| 三层防线防"假成功"：服务端模板 → 断言闸门（扫"已采集成功"等字样）→ `_pack()` 二次保险 | 同上 |
| 润色模式必须过闸门**且数字集合不变**（模型会把"12 条"写成"10 条"） | 同上 |
| 密钥只留服务端：从环境变量读，`/api/agent/info` 只回 `has_key` 布尔值 | 同上 |

## 二、实测数据

| 用例 | 结果 |
|---|---|
| 「看看数据吧」（含糊） | `intent=unclear`，列出两个可选项，**不执行任何动作** |
| 「采 500 个点」（越界） | 限幅到 100 并在回答里说明，不静默改 |
| 「给 device999 重新采集」（越界设备） | `error=device_not_allowed`，未执行 |
| 离线设备请求采集 | `error=device_offline`，未下发 |
| 无完成证据（timeout / failed / issued） | 三种状态逐一检查，**回答里都没有成功声明** |

**统计：32 项中 ✅ 27 项、⚠️ 3 项、❌ 2 项。**

两项 ❌ 是要外部条件的：教师提供的授权运行时语言服务、教师提供的结构化错误样例
（本项目用本地 Ollama 和自建样例顶替，如实记为未做）。

## 三、怎么跑起来

```bash
# 1) 先起语言服务（不能直接开 Ollama 托盘程序，否则 /api/tags 为空、助手全返回 llm_unavailable）
week1\启动语言服务.bat

# 2) 再起数据服务
cd week1/server
python server.py --port 8000 --host 0.0.0.0
```

- 网页：<http://127.0.0.1:8000/#nl>（受限语言入口）
- 检查模型是否加载：`curl http://127.0.0.1:11434/api/tags` 应看到 4 个模型
- 离线自测：`python week1/tools/test_llm_fallback.py`

## 五、分支与周次对照

仓库按周打了快照分支。**远端默认分支是 `main`，含全部已完成周次**；
想看某一周结束时的状态，切到对应分支即可。

| 分支 | 对应阶段 | 说明 |
|---|---|---|
| **`main`**（远端默认分支） | 最新主线 | 含第 1—7 周全部内容 |
| `week7` | 第 7 周 | 按需获取一张环境图像（采集四态 + "是不是本次拍的"判定） |
| `week6` | 第 6 周 | 语音任务的澄清与停止（有限多轮上下文、取消、迟到结果隔离） |
| `week5` | 第 5 周 | 按键说话 + 板载麦克风录音 + 离线识别 + 语音播报 |
| `week4` | 第 4 周 | 自然语言查询与请求采集（两个受限工具，本文档所在分支） |
| `week3` | 第 3 周 | 实体按键发起教学求助 + 反馈闭环 + 回应与取消 |
| `week2` | 第 2 周 | 双向指令通道 + 回执状态机 |
| `week1` | 第 1 周 | 单源采集 + 上行链路 + Web 实时展示 |

每个 `weekN` 分支是**累积快照**：含第 1 周到第 N 周的全部文件，不是只放那一周的增量。
