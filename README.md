# 第 3 周 · 按板子上的键，能立刻得到回应

> 这是**第 3 周结束时**的仓库快照。整门课的完整说明看
> [`main` 分支](https://github.com/No3799/esp32s3-eye-interaction/tree/main)。

网页点一下、设备执行 —— 这样的交互全部发生在远端。可是站在设备旁边的那个人，
反而没有办法和它说话：只能等，或者掏出手机打开网页。

这一周把**按键**接上：按一下就能发起一次教学求助测试消息，本机立刻有反馈，
远端网页能看到这次操作，查看者可以回应或者取消。

## 一、这一周做了什么

| 做了什么 | 落在哪 |
|---|---|
| 四个按键的电压判读：共用同一根 ADC 电阻梯（GPIO1），空闲 3162 mV，UP+/DN−/PLAY/MENU 实测 365 / 800 / 1981 / 2414 mV | `firmware/esp32_imu/main/main.c`、`tools/btn_probe.py` |
| 本地反馈只有一颗绿灯（GPIO3）—— 本板**没有蜂鸣器、没有可编程 RGB**；这颗灯必须**开漏输出、不得上拉**，否则可能烧灯 | `main.c` |
| 按键发起「教学求助测试消息」，而不是单纯采一批数据 | `POST /api/help` |
| 三级反馈严格分开：**本地确认 / 服务器接收 / 查看者回应**；没有远端证据就不显示"对方已收到" | [`docs/design/11`](docs/design/11-教学求助与回应闭环.md) |
| 回应 / 取消闭环：取消只改状态，**不删记录**（事件本身确实发生过） | `POST /api/help/<id>/reply` |
| 设备事件 id 加上电随机前缀 `BTN-<6hex>-MENU-0001` | `main.c` |
| 灯效走队列 + `led_task`；按键采集放主循环（HTTP 客户端是全局单使用者） | `main.c` |
| 三课接口检查：首版事件与命令字段逐项对照 | [`docs/design/12`](docs/design/12-三课接口对照-首版事件与命令字段.md) |

**为什么事件 id 要带随机前缀**：内存计数器一重启就归零，两次按键会产生同一个 id，
服务器按 id 合并事件时会**把两次按键并成一条**。加上电前缀后 id 跨重启唯一。

## 二、实测数据

| 项目 | 结果 |
|---|---|
| 按键电压 | 最大偏差 −20 mV，最小档间距 430 mV —— 原理图设计值可直接用于判读 |
| 上电自检 | 绿灯连闪 3 次（人眼确认） |
| 按键事件 | 5 次按键 + 后续取消共 **14 条事件全部保留**，只把状态标 `cancelled` |
| **断网实测** | 停服后轮询确认**静默 71.5 秒、窗口内 0 条**；恢复后 **0.0 秒**接上，**没有补发** |
| 断网时按键 | 本地仍能确认"已触发"（绿灯），网页侧不会出现任何伪造的"已收到" |

断网这一步必须三步走：取基线 → 停服务器 → **轮询确认连续 4 秒零新增**才能请人按键。
第三步不能省：停服要几秒，那几秒服务器还活着，误收的记录会让整轮作废。

## 三、怎么跑起来

```bash
cd week1/server
python server.py --port 8000 --host 0.0.0.0
```

- 网页：<http://127.0.0.1:8000/#help>（教学求助面板）
- 按键电压核验：`python week1/tools/btn_probe.py`（需要人按键）
- 无硬件自测：`python week1/tools/btn_selftest.py`

## 五、分支与周次对照

仓库按周打了快照分支。**远端默认分支是 `main`，含全部已完成周次**；
想看某一周结束时的状态，切到对应分支即可。

| 分支 | 对应阶段 | 说明 |
|---|---|---|
| **`main`**（远端默认分支） | 最新主线 | 含第 1—7 周全部内容 |
| `week7` | 第 7 周 | 按需获取一张环境图像（采集四态 + "是不是本次拍的"判定） |
| `week6` | 第 6 周 | 语音任务的澄清与停止（有限多轮上下文、取消、迟到结果隔离） |
| `week5` | 第 5 周 | 按键说话 + 板载麦克风录音 + 离线识别 + 语音播报 |
| `week4` | 第 4 周 | 自然语言查询与请求采集（两个受限工具） |
| `week3` | 第 3 周 | 实体按键发起教学求助 + 反馈闭环 + 回应与取消（本文档所在分支） |
| `week2` | 第 2 周 | 双向指令通道 + 回执状态机 |
| `week1` | 第 1 周 | 单源采集 + 上行链路 + Web 实时展示 |

每个 `weekN` 分支是**累积快照**：含第 1 周到第 N 周的全部文件，不是只放那一周的增量。
