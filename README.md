# 第 5 周 · 对着板子说一句话，它就能办事

> 这是**第 5 周结束时**的仓库快照。整门课的完整说明看
> [`main` 分支](https://github.com/No3799/esp32s3-eye-interaction/tree/main)。

要点按钮才能触发的东西，开口说一句也应该能触发。这一周把**声音**接进链路：

```
按住说话 → 板载麦克风录音 → 识别成文字 → 走同一个任务入口 → 播报结果
```

关键原则只有一句：**语音只是换了一种输入和输出方式，不是新开一条业务链路**。
识别出来的文字走的就是原来那个 `/api/ask`，没有另起一条路径 ——
两条路径迟早会长出两种行为。

## 一、这一周做了什么

| 做了什么 | 落在哪 |
|---|---|
| 板载数字麦 **MSM261S4030H0R**（I2S，SCK=41 / WS=42 / SD=2），直接采 PCM | `firmware/esp32_imu/main/mic_record.c` |
| 用 **BOOT 键（GPIO0）** 开始/结束录音。**没有复用四个用户键** —— 那四个键已经绑死"按一下=发求助"，叠加长按会改动已验证的触发语义 | `main.c` |
| 网页侧另一条入口：Web Audio 采集 → 降采样 16k → WAV → `POST /api/asr` | `web/index.html` |
| 板载录音走 `POST /api/audio`（二进制上传），服务器存 WAV 并可回灌识别 | `server/server.py` |
| 离线中文识别：Vosk 中文模型，独立虚拟环境 `.venv-asr` | `server/asr_worker.py` |
| 播报：浏览器 `speechSynthesis`；**板子本身没有扬声器，不会出声** | `web/index.html` |
| 界面四态：录音中 / 识别中 / 执行中 / 播报中，任何一环坏掉都能指到具体位置 | 同上 |
| 识别超时给可理解的反馈（`asr_timeout` → 建议改用文字），并把阈值做成可覆盖，用 0.05 秒真打一次 | `server.py` |

## 二、实测数据

| 项目 | 结果 |
|---|---|
| 真语音 ①（13:55:17） | 板载麦录 **105,004 字节 ≈3.3 秒**（未截断）→ 识别为「你好」→ 走追问 |
| 真语音 ②（14:01:52） | 录「查看上次数据」→ `query_latest` → 读到真实记录 |
| 合成引擎 | `check_tts.py` 实跑 **4.27 秒**（9 次 boundary、无报错） |
| 录音回灌 | 用服务器上存的真人录音（87KB）回灌 `/api/asr` → 识别出同一句，耗时 1.66 秒 |
| 文字入口兜底 | 先让麦克风失败，再用真鼠标点「发送」→ 拿到回答，按钮没卡在禁用态（11 项全过） |

**统计：19 项中 ✅ 16 项、⚠️ 1 项、❌ 2 项。**

- 唯一没证的是"**人耳听到播报**"：这台电脑没有扬声器，属环境限制，不写成"已验证"
- 两项 ❌ 要外部条件：教师验证麦克风/识别/合成服务、共享音频站现场补验

## 三、怎么跑起来

```bash
# 1) 识别服务（独立环境，模型不入库）
week1\.venv-asr\Scripts\python.exe week1\tools\asr_worker.py

# 2) 数据服务
cd week1/server
python server.py --port 8000 --host 0.0.0.0
```

- 网页：<http://127.0.0.1:8000/#nl>，点「按住说话」或按板子上的 BOOT 键
- 检查识别链路：`python week1/tools/test_asr_paths.py`

## 五、分支与周次对照

仓库按周打了快照分支。**远端默认分支是 `main`，含全部已完成周次**；
想看某一周结束时的状态，切到对应分支即可。

| 分支 | 对应阶段 | 说明 |
|---|---|---|
| **`main`**（远端默认分支） | 最新主线 | 含第 1—7 周全部内容 |
| `week7` | 第 7 周 | 按需获取一张环境图像（采集四态 + "是不是本次拍的"判定） |
| `week6` | 第 6 周 | 语音任务的澄清与停止（有限多轮上下文、取消、迟到结果隔离） |
| `week5` | 第 5 周 | 按键说话 + 板载麦克风录音 + 离线识别 + 语音播报（本文档所在分支） |
| `week4` | 第 4 周 | 自然语言查询与请求采集（两个受限工具） |
| `week3` | 第 3 周 | 实体按键发起教学求助 + 反馈闭环 + 回应与取消 |
| `week2` | 第 2 周 | 双向指令通道 + 回执状态机 |
| `week1` | 第 1 周 | 单源采集 + 上行链路 + Web 实时展示 |

每个 `weekN` 分支是**累积快照**：含第 1 周到第 N 周的全部文件，不是只放那一周的增量。
