# 第 6 周 · 听错了、改主意了、回答来晚了

> 这是**第 6 周结束时**的仓库快照。整门课的完整说明看
> [`main` 分支](https://github.com/No3799/esp32s3-eye-interaction/tree/main)。

系统听懂一句话只是开始。真实使用里三件事一定会发生：

- 它**听错了**（或者没把握）→ 要能问回去，而不是瞎猜一个执行
- 用户**改主意了** → 要能停下，而且停下之后不能又被旧结果打断
- 回答**来晚了** → 迟到的结果不能重新播报、不能改当前状态

这一周做的就是这三件事。

## 一、这一周做了什么

| 做了什么 | 落在哪 |
|---|---|
| 有限多轮上下文：每会话只记 **1 条**待答问题，TTL **180 秒**，上限 200 个会话 | `server/turn_context.py` |
| 澄清：服务端返回 `clarify{question,options}`，前端渲染成按钮让人点 | `server.py` + `web/index.html` |
| 取消：`stopAll()` —— 代数 +1 / abort 在途请求 / 停播报 / 回空闲 | `web/index.html` |
| **迟到结果隔离**：`myGen !== gen` 就丢弃 —— 不写对话、不播报、不改状态 | 同上 |
| 停止播报：`speechSynthesis.cancel()`；念到一半按 Esc 立刻静音 | 同上 |
| 重新输入：取消时把原文填回输入框，不自动重发 | 同上 |
| 半双工形态：按一下说、再按一下结束。唤醒 / 回声消除 / 全双工作为拓展，**均未做** | [`docs/design/15`](docs/design/15-语音任务的澄清与停止.md) §9 |
| 向端侧课反馈取消语义与反馈时序需求（材料已备，**未真正交付**） | [`docs/design/16`](docs/design/16-端侧协同-取消语义与反馈时序需求.md) |

**为什么用"代数"而不是"取消标记"**：一个布尔标记无法区分"这一轮被取消了"和
"上一轮的结果这时候才回来"。每发起一次任务代数 +1，回调只认同代，晚到的自然对不上。

## 二、实测数据

| 项目 | 结果 |
|---|---|
| 输入结束 → 首次反馈 | **17 ~ 32 ms**（6 次记录，中位 28 ms；双 `requestAnimationFrame` 取值） |
| → 任务完成（读记录） | 2.95 ~ 3.07 秒 |
| → 任务完成（请求采集） | 6.4 秒（含设备回执） |
| 取消后 | 等 **12 秒**，状态没有被改回「完成」 |
| 注入 3 秒慢响应 | 客户端实测 6023 ms，但界面 **0.35 秒**就显示「处理中…」 |
| 连续两次查询 | 各占一条气泡，`bot` 计数 +2，互不覆盖 |

**统计：27 项中 ✅ 23 项、⚠️ 3 项、❌ 1 项。**

- ⚠️ 三项：端侧课需求"材料已备未交付"、"语言交互版本"这条原文含义不确定（按打版本快照处理）、
  用户反悔恢复规则**没跑浏览器验证**
- ❌ 一项：教师提供的迟到响应与错误识别测试入口（自建了 `delay_ms` 注入与提示音两条等价入口）

## 三、怎么跑起来

```bash
# 起服务要带故障注入开关，慢响应与错误识别才测得了
python week1\server\server.py --port 8000 --host 0.0.0.0 --fault-injection
```

- 网页：<http://127.0.0.1:8000/#nl>
- 上下文 / 取消 / 澄清自测：`python week1/tools/test_week6_context.py`、`test_week6_state.py`
- 时序测量：`python week1/tools/measure_week6_timing.py`（会写 `week1/第6周时序记录.md`）

## 五、分支与周次对照

仓库按周打了快照分支。**远端默认分支是 `main`，含全部已完成周次**；
想看某一周结束时的状态，切到对应分支即可。

| 分支 | 对应阶段 | 说明 |
|---|---|---|
| **`main`**（远端默认分支） | 最新主线 | 含第 1—7 周全部内容 |
| `week7` | 第 7 周 | 按需获取一张环境图像（采集四态 + "是不是本次拍的"判定） |
| `week6` | 第 6 周 | 语音任务的澄清与停止（有限多轮上下文、取消、迟到结果隔离，本文档所在分支） |
| `week5` | 第 5 周 | 按键说话 + 板载麦克风录音 + 离线识别 + 语音播报 |
| `week4` | 第 4 周 | 自然语言查询与请求采集（两个受限工具） |
| `week3` | 第 3 周 | 实体按键发起教学求助 + 反馈闭环 + 回应与取消 |
| `week2` | 第 2 周 | 双向指令通道 + 回执状态机 |
| `week1` | 第 1 周 | 单源采集 + 上行链路 + Web 实时展示 |

每个 `weekN` 分支是**累积快照**：含第 1 周到第 N 周的全部文件，不是只放那一周的增量。
